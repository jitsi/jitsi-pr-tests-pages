Jitsi PR test reports

This site hosts per-PR CI test artifacts for the Jitsi projects.

Reports live at:

/<source-repo>/PR-<number>/<build>/

For example: jitsi-meet/PR-17436/20120/

You usually reach a specific report through the “Details” link on the PR check in the source repository, not by browsing here.

Source & retention policy: github.com/jitsi/jitsi-pr-tests-pages
