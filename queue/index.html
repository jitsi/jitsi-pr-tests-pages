Waiting for the runner: the repo's runner is busy with an earlier run of the same repo. Waiting for the test machine: the run has its runner and waits for the run that is testing. Of the runs that have their runner, the one that got it first is shown as testing. That is almost always right, the run log on GitHub shows it for sure.
The results of the finished runs are those of the PR check. Older builds, published before the reports carried their result, show "in the report".
This page reads the public GitHub API from your browser, without signing in. GitHub allows 60 such requests an hour per IP address, shared by everyone behind the same address, and one refresh uses 6 to 12 of them, so about 5 to 10 refreshes an hour. The page refreshes every 10 minutes while it is open.
